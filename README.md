# 🎙️ FluentVoice AI — Conversational English Coach (Basic to Pro)

An interactive, voice-first AI English coach built to take learners from **Basic (A1-A2)** to **Pro (C1-C2)** fluency with real-time grammar repair, vocabulary upgrades, and immersive roleplay scenarios.

## ✨ Features

- 🌌 **Modern Ethereal Voice UI**:
  - Deep obsidian canvas (#07080B) with reactive radial aurora glow.
  - Multi-layer **Living Voice Sphere** with audio equalizer wave bars (inspired by ChatGPT Voice and iOS Siri).
  - Floating frosted glass iOS pill dock with spring physics.

- 🗣️ **Proficiency Ladder (CEFR Aligned)**:
  - **Basic (A1-A2)**: Patient pacing, gentle corrections, fundamental grammar focus.
  - **Intermediate (B1-B2)**: Fluid conversational practice, idioms, and natural discourse markers.
  - **Pro (C1-C2)**: Executive presence, elimination of filler words, sophisticated rhetorical vocabulary.

- 🧠 **Cambridge CEFR & ESL Dataset Engine**:
  - **50+ ESL Grammatical Error Correction (GEC) Rules**: Tense consistency, preposition accuracy, uncountable nouns (*advices*, *furnitures*), collocations, and false friends.
  - **Vocabulary Enrichment**: Automatically surfaces level-appropriate upgrades with 1-tap bookmarking to your **Personal Vocab Vault**.

- ⚡ **Multi-Model AI Gateway**:
  - **Smart In-Browser Engine (Default)**: 100% free, runs offline, zero API keys required.
  - **Groq Cloud**: Ultra-fast ~200ms latency via Llama 3.3 70B & Whisper.
  - **Google Gemini Flash**: Free tier (1,500 requests/day).
  - **Hugging Face Serverless**: Open-source inference (e.g. Mistral-7B).

- 🎭 **Roleplay Scenarios & Vocab Vault**:
  - Practice real-world scenarios: Executive Job Interview, Pitching to Investors, Crisis Management, Impromptu Debate, and Airport Travel.
  - Vocab Vault flashcards with native speech synthesis (TTS) pronunciation drills.

## 🚀 Quick Start (Local Development)

### 1. Clone the repository
`ash
git clone https://github.com/pawan200924-coder/English-Coach.git
cd English-Coach
`

### 2. Install dependencies
`ash
npm install
`

### 3. Run the development server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploy to Vercel

The easiest way to deploy is through [Vercel](https://vercel.com/new):

1. Import your GitHub repository (pawan200924-coder/English-Coach).
2. Keep default build settings (
ext build).
3. Deploy!

Permissions note: Audio capture requires microphone permissions (Permissions-Policy: microphone=(self)), which is pre-configured in ercel.json.
